        <h2>Multiple Outputs</h2>
        <pre>&lt;?php
echo "Thank You Cena!&lt;br&gt;";
echo "Acknowledge Me.&lt;br&gt;";

    <div class="activity-card">
        <span class="label">ACTIVITY 3</span>
        <h2>Declaring Variables</h2>
        <pre>&lt;?php
$name = "Sanchez";
$age = 19;

echo "Name: " . $name . "&lt;br&gt;";
echo "Age: " . $age;
?&gt;</pre>
        <div class="explanation">
            <strong>Key Concept:</strong> Variables in PHP always start with <code>$</code>. We use the period <code>.</code> (concatenation operator) to join strings and variables.
        </div>
    </div>

    <div class="activity-card">
        <span class="label">ACTIVITY 4</span>
        <h2>Variable Rules (Fixed)</h2>
        <pre>&lt;?php
$name = "Sanchez"; // Fixed: removed '1' from start
$age = 19;    // Fixed: matched lowercase 'age'
echo $age;    
?&gt;</pre>
        <div class="explanation">
            <strong>Correction:</strong> 1. Variable names <span class="answer-key">cannot start with numbers</span>. 2. PHP is <span class="answer-key">case-sensitive</span>, so <code>$Age</code> and <code>$age</code> are different.
        </div>
    </div>

    <div class="activity-card">
        <span class="label">ACTIVITY 5</span>
        <h2>Arithmetic Operators</h2>
        <pre>&lt;?php
$a = 10;
$b = 3;

echo "Addition: " . ($a + $b) . "&lt;br&gt;";
echo "Subtraction: " . ($a - $b) . "&lt;br&gt;";
?&gt;</pre>
        <div class="explanation">
            <strong>Results:</strong> Addition is <span class="answer-key">13</span>, Subtraction is <span class="answer-key">7</span>, Multiplication is <span class="answer-key">30</span>, and Division is <span class="answer-key">3.33...</span>.
        </div>
    </div>

    <div class="activity-card">
        <span class="label">ACTIVITY 6</span>
        <h2>Assignment Operators</h2>
        <pre>&lt;?php

echo $x;
?&gt;</pre>
        <div class="explanation">
            <strong>Question:</strong> What will be the output?<br>
            <strong>Answer:</strong> <span class="answer-key">8</span>

$a = 10;
